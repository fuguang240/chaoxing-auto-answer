# 学习通全自动答题助手 v2.2

超星学习通（泛雅平台）作业**全自动** Chrome 插件。

## 🚀 v2.2 全新功能

### 三大题型全支持
- ✅ **单选题** - 全自动答题
- ✅ **多选题** - 自动识别，多选答案
- ✅ **文字输入题** - 批量填入优化后的答案

### 完整工作流
```
选择题：一键全自动（无人值守）
文字题：毛坯答案 → AI优化 → 粘贴填入
最后：暂时保存 → 检查 → 提交
```

---

## 功能特点

- **全自动选择题**：点一下就完事，无人值守
- **智能答题引擎**：内置60+条AI/算法规则
- **文字题批量填入**：支持填空题、简答题
- **精准识别**：直接操作 DOM 元素，准确率 100%
- **一键保存/提交**：内置保存和提交按钮

## 使用方法

### 1. 选择题全自动
1. 打开学习通作业答题页面
2. 点击浏览器右上角的插件图标
3. 点击「⚡ 一键全自动（选择题）」
4. 确认后等待，全程自动完成

### 2. 文字题填写
1. 把你的毛坯答案（关键词/大概意思）发给我
2. 我帮你优化成标准答案
3. 把优化后的答案粘贴到插件的文字题输入框
4. 点击「填入文字题答案」

### 3. 保存提交
1. 点击「暂时保存」检查所有答案
2. 确认无误后点击「直接提交」

## 核心方法论

### 最高准确率点击方式
- 每个题目的选项 span 元素 class 为 `choice{题目ID} num_option fl`
- **直接点击 span 元素（选项字母）**，准确率 100%

### 算力消耗最小化
- 无需 OCR 识别，直接读取 DOM 结构
- 无需截图，纯 DOM 操作
- 批量处理，单次调用完成所有题目

### 智能答案匹配引擎
内置规则库覆盖：
- 遗传算法（编码、适应度、交叉、变异、选择）
- 搜索算法（BFS、UCS、DLS、A算法、启发式）
- 蚁群算法（信息素、正反馈、蚁周模型）
- 粒子群算法（惯性权重、c1/c2参数）
- 神经网络（CNN、RNN、Transformer、BP）

兜底策略：自动选择最完整、最全面的选项。

## 安装方法

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本插件文件夹即可
