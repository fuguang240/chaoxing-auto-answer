# 学习通自动答题助手

超星学习通（泛雅平台）作业自动答题 Chrome 插件。

## 功能特点

- **精准识别**：自动识别页面上的所有单选题
- **批量填写**：粘贴答案列表，一键批量选择所有选项
- **高效准确**：直接操作 DOM 元素，点击准确率 100%
- **一键保存/提交**：内置保存和提交按钮

## 使用方法

1. 打开学习通作业答题页面
2. 点击浏览器右上角的插件图标
3. 在答案输入框中，按题目顺序每行输入一个答案（A/B/C/D）
4. **先确认答案无误**，再点击「批量填写答案」
5. 确认所有答案正确选中后，再点击「暂时保存」或「直接提交」

## 核心方法论

### 最高准确率点击方式

经过实际测试，超星学习通答题页面：

1. 每个题目的选项 span 元素 class 为 `choice{题目ID} num_option fl`
2. **直接点击 span 元素（选项字母）**，而不是整个选项行，这样 100% 准确
3. 选中状态：选项圆圈变成蓝色实心

### 算力消耗最小化

- 无需 OCR 识别，直接读取 DOM 结构
- 无需截图，纯 DOM 操作
- 批量处理，单次调用完成所有题目

## 安装方法

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本插件文件夹即可
