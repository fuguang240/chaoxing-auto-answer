## 功能特点

- **全自动模式**：点一下就完事，无人值守
- **智能答题引擎**：内置60+条AI/算法规则，覆盖遗传算法、搜索、蚁群、粒子群、神经网络等
- **精准识别**：直接操作 DOM 元素，点击准确率 100%
- **手动模式**：支持手动粘贴答案批量填写
- **一键保存/提交**：内置保存和提交按钮

## 使用方法

### 全自动模式（推荐）
1. 打开学习通作业答题页面
2. 点击浏览器右上角的插件图标
3. 点击「⚡ 一键全自动开始」
4. 确认后等待，全程自动完成
5. ✅ 答完自动保存

### 手动模式
1. 在答案输入框中，按题目顺序每行输入一个答案（A/B/C/D）
2. 点击「批量填写答案」
3. 确认所有答案正确选中后，再点击「暂时保存」或「直接提交」

## 核心方法论

### 最高准确率点击方式

经过实际测试，超星学习通答题页面：

1. 每个题目的选项 span 元素 class 为 `choice{题目ID} num_option fl`
2. **直接点击 span 元素（选项字母）**，而不是整个选项行，这样 100% 准确
3. 选中状态：选项圆圈变成蓝色实心

### 算力消耗最小化

- 无需 OCR 识别，直接读取 DOM 结构
- 无需截图，纯 DOM 操作
- 批量处理，单次调用完成所有题目

### 智能答案匹配引擎

内置规则库，覆盖：
- 遗传算法（编码、适应度、交叉、变异、选择）
- 搜索算法（BFS、UCS、DLS、A算法、启发式）
- 蚁群算法（信息素、正反馈、蚁周模型）
- 粒子群算法（惯性权重、c1/c2参数）
- 神经网络（CNN、RNN、Transformer、BP、激活函数）
- 逻辑推理（谓词逻辑、消解原理）

兜底策略：自动选择最完整、最全面的选项。

## 安装方法

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本插件文件夹即可
